# Оил Маркет — сайт автокомплекса (Магнитогорск)

Статический многостраничник: чистые HTML/CSS/JS, без сборки и фреймворков.
Содержимое папки заливается на хостинг как есть (reg.ru / ISPmanager → каталог сайта).

## Структура

```
index.html          Главная: приборная панель, акция, услуги, розница
services.html       Услуги: ТО, замена масла, шиномонтаж
catalog.html        Шины и масла: витрина категорий, масла «Оил»
reviews.html        Отзывы: рейтинг 4.4 / 267 и лента под выгрузку
contacts.html       Контакты, схема проезда, форма записи
css/oil.css         Дизайн-система и вёрстка
css/fonts.css       @font-face локальных шрифтов
js/oil.js           Вся логика: приборы, меню, фильтр, карусель, форма
assets/fonts/       Golos Text 900, IBM Plex Sans, IBM Plex Mono (woff2, OFL)
assets/img/         Пусто: сюда кладутся фотографии клиента
```

## Дизайн-система

| Роль | Токен | Значение |
|---|---|---|
| Фон | `--asphalt` | `#121214` |
| Поверхности | `--steel` | `#1E1F22` |
| Вторичный текст, линии | `--chrome` | `#9AA0A6` |
| Акцент, активное состояние | `--red` | `#D81E2C` |
| Акция, предупреждение | `--amber` | `#F2A900` |
| Основной текст | `--white` | `#F5F5F0` |

Шрифты: **Golos Text 900** — заголовки, **IBM Plex Sans** — проза,
**IBM Plex Mono** — все измеримые величины (рейтинг, телефоны, часы,
типоразмеры, вязкости).

> **Почему не Archivo Black.** У Archivo нет кириллического подмножества —
> русские заголовки молча падали бы в Arial Black. Взят Golos Text 900:
> тот же тяжёлый индустриальный гротеск, но с полной кириллицей.
> Если понадобится вернуть Archivo для латиницы — правится один токен
> `--f-display` в `css/oil.css`.

Шрифты лежат локально: сайт не обращается к сторонним доменам, ничего
не ломается, если Google Fonts недоступен.

## Отзывы

Тексты отзывов не выдуманы и не будут. Лента читает массив `REVIEWS` в начале
`js/oil.js`:

```js
var REVIEWS = [
  { text: "…", author: "Имя И.", date: "2026-05-14", stars: 5 }
];
```

Пустой массив → в карусели стоят слоты «ожидает выгрузки». Заполненный →
карусель рендерит реальные отзывы, вёрстку трогать не нужно.

## Формы

Приём заявок с сайта — следующий этап. Сейчас форма валидирует имя и телефон
и показывает честное сообщение: заявка передаётся администратору, а быстрее
позвонить. Точка интеграции — обработчик `initForms()` в `js/oil.js`:
туда добавляется `fetch()` на почтовый скрипт хостинга или в CRM.

## Проверено

- Хром/десктоп 1440 и мобильный 390 — без горизонтальной прокрутки, без ошибок в консоли.
- `prefers-reduced-motion` — стрелка и одометр встают в конечное положение без анимации.
- Без JS — приборы показывают итоговые значения (4.4, 267), навигация и телефоны работают.
- Клик-звонок на всех CTA, фикс-полоса «Позвонить / Записаться» на мобильном.
- Видимый focus-state (янтарная обводка) на всех интерактивных элементах.
