# Логотипы полосы интеграций

Положите SVG с этими именами, и они подхватятся сами: на месте логотипа
пропадёт текстовое название сервиса и появится картинка.

Требования к файлу: SVG, высота приводится к 24px автоматически, ширина
произвольная. Цвет внутри файла не важен — он приводится к одному тону
фильтром, поэтому подойдёт любой фирменный вариант, кроме белого на
прозрачном (он станет невидимым, для таких берите тёмную версию).

```
telegram.svg
whatsapp.svg
2gis.svg
yandex-metrica.svg
amocrm.svg
bitrix24.svg
yookassa.svg
google-sheets.svg
notion.svg
airtable.svg
n8n.svg
make.svg
supabase.svg
vercel.svg
cal-com.svg
gohighlevel.svg
claude.svg
```

Список и порядок задаются в разметке `index.html`, секция
`<section class="strip">`. Набор продублирован дважды подряд — это нужно
для бесшовной прокрутки, поэтому правки вносите в обе копии. Во второй
копии у `<img>` пустой `alt`, а у списка `aria-hidden="true"`: скринридер
читает названия один раз.
