# Логотипы полосы интеграций

Логотипы собраны прямо в разметке, а не подгружаются файлами. Каждый
состоит из знака (inline SVG) и начертания (текст с собственной плотностью
и трекингом). Знаки нарисованы приближённо и служат заглушкой до тех пор,
пока вы не вставите официальные файлы.

## Как заменить на официальный логотип

Откройте `index.html`, секцию `<section class="strip">`. Каждый логотип
помечен комментарием:

```html
<li class="logo-item lg-vercel">
  <!-- Vercel: заменить знак и начертание на официальный логотип из img/logos/vercel.svg -->
  <svg class="logo-item__mark" viewBox="0 0 24 24" aria-hidden="true" focusable="false">…</svg>
  <span class="logo-item__word">Vercel</span>
</li>
```

Замените содержимое `<li>` на официальный SVG целиком (обычно он включает
и знак, и начертание). Что важно сохранить:

- высоту 24px и корректный `viewBox`, ширина произвольная;
- `fill="currentColor"` вместо фирменного цвета: цвет и прозрачность
  берутся с `.logo-item`, это `--fg` при 0.8 и 1.0 на наведении;
- если официальный SVG уже содержит начертание, уберите `<span
  class="logo-item__word">`, иначе название продублируется.

Атрибуты `width`, `height` и жёстко заданные цвета внутри чужого SVG лучше
почистить, иначе они перебьют стили полосы.

## Набор и порядок

```
vercel.svg     Vercel
claude.svg     Claude
linear.svg     Linear
supabase.svg   supabase
framer.svg     Framer
notion.svg     Notion
telegram.svg   Telegram
```

У всех семи логотипов есть знак: вспышка Claude и скруглённый квадрат
Linear нарисованы так же приближённо, как остальные.

## Что проверить после замены

Набор продублирован в разметке дважды подряд — это нужно для бесшовной
прокрутки, поэтому правьте обе копии. Во второй копии у списка стоит
`aria-hidden="true"`: скринридер читает названия один раз.

Суммарная ширина одного набора должна быть больше ширины окна ленты,
иначе в стыке появится пустое место. Сейчас набор занимает 1025px при окне ленты 832px на контейнере 1200px.
