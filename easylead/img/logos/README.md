# Логотипы полосы интеграций

Логотипы вставлены прямо в разметку как inline SVG, а не через `<img>`.
Сейчас на месте каждого стоит блок-заглушка: прямоугольник 24px высотой
со скруглением 6px, залитый `currentColor`.

## Как заменить

Откройте `index.html`, секцию `<section class="strip">`. Каждый логотип
помечен комментарием:

```html
<li class="logo-item">
  <!-- Telegram: заменить этот svg на содержимое img/logos/telegram.svg -->
  <svg width="108" height="24" viewBox="0 0 108 24" role="img" aria-label="Telegram" focusable="false">
    <rect width="108" height="24" rx="6" fill="currentColor"/>
  </svg>
</li>
```

Замените весь тег `<svg>` содержимым своего файла. Что важно сохранить:

- `height="24"` и корректный `viewBox`, ширина произвольная;
- `role="img"` и `aria-label` с названием сервиса в первом наборе;
- заливку `fill="currentColor"` вместо фирменного цвета, если хотите
  монохромный ряд. Цвет и прозрачность берутся с родителя `.logo-item`:
  `--fg` при 0.45, на наведении 0.8.

Атрибуты `width`, `height`, `fill` и `stroke` внутри чужого SVG лучше
почистить, иначе они перебьют стили полосы.

## Набор и порядок

```
telegram.svg
whatsapp.svg
yandex.svg
2gis.svg
yookassa.svg
google-sheets.svg
```

Набор продублирован в разметке дважды подряд: это нужно для бесшовной
прокрутки, поэтому правьте обе копии. Во второй копии у списка стоит
`aria-hidden="true"`, а у svg нет `aria-label` — скринридер читает
названия один раз.

Ширина блоков влияет на длину ленты. После замены проверьте, что суммарная
ширина одного набора больше ширины окна ленты, иначе в стыке появится
пустое место.
