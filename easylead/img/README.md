# Изображения

Все плейсхолдеры на сайте уже ссылаются на файлы из этой папки. Положите
картинку с нужным именем, и она подхватится сама: блок-заглушка исчезнет,
подпись под ней тоже.

Формат: PNG или JPG. Пропорции указаны в таблице, их лучше соблюдать,
иначе изображение обрежется по центру (`object-fit: cover`).

|---|---|---|---|

| `case-gbo.png` | Главная, Работы | 16:10 | 1600 x 1000 |
| `case-cleaning.png` | Главная, Работы | 16:10 | 1600 x 1000 |
| `case-ceilings.png` | Главная, Работы | 16:10 | 1600 x 1000 |
| `case-body.png` | Работы | 16:10 | 1600 x 1000 |
| `case-dental.png` | Работы | 16:10 | 1600 x 1000 |
| `case-water.png` | Работы | 16:10 | 1600 x 1000 |
| `service-multipage.png` | Услуги | 3:2 | 1500 x 1000 |
| `service-landing.png` | Услуги | 3:2 | 1500 x 1000 |
| `service-widgets.png` | Услуги | 3:2 | 1500 x 1000 |
| `service-automation.png` | Услуги | 3:2 | 1500 x 1000 |

Если имя файла нужно поменять, правьте атрибут `src` у соответствующего
`<img class="media__img">` и текст подписи `<figcaption>` в HTML.
