# EasyLead

Многостраничный сайт агентства EasyLead: разработка сайтов и автоматизаций
для локального бизнеса. Чистый HTML, CSS и ванильный JavaScript, без
сборщиков, фреймворков и CDN-зависимостей кроме шрифта Google Fonts.

## Структура

```
easylead/
├── index.html      главная
├── services.html   услуги
├── cases.html      работы
├── about.html      о нас
├── pricing.html    цены
├── contact.html    контакты и форма заявки
├── style.css       общая дизайн-система и все стили
├── script.js       шапка, меню, аккордеон, форма, модалка
└── img/            плейсхолдеры изображений, см. img/README.md
```

Шапка и подвал продублированы в разметке каждой страницы, а не собираются
скриптом: страницы должны открываться и читаться без JavaScript.

## Что нужно сделать перед публикацией

1. **Подключить форму.** В начале `script.js` замените константу:
   ```js
   const FORM_ENDPOINT = 'ЗАМЕНИТЬ_НА_URL_ВОРКЕРА';
   ```
   Пока стоит заглушка, форма не отправляет данные и честно пишет об этом
   под кнопкой. Токены, ключи и `chat_id` во фронтенде не хранятся: воркер
   должен принимать `POST` с JSON вида
   ```json
   {
     "name": "Марина",
     "phone": "+7 (916) 123-45-67",
     "niche": "Автосервис и автотовары",
     "comment": "",
     "page": "Главная",
     "url": "https://example.ru/index.html"
   }
   ```
   Успешным считается любой ответ со статусом 2xx.

2. **Подставить контакты.** Телефон, Telegram и почта заданы заглушками в
   двух местах: константа `CONTACTS` в начале `script.js` (для модалки) и
   разметка шапки, подвала, тёмных CTA-блоков и `contact.html`. Найти всё
   сразу можно поиском по `+7 (999) 000-00-00`, `@easylead` и
   `hello@easylead.ru`.

3. **Проверить цены.** Суммы в `pricing.html` и в блоке вопросов на главной
   поставлены как рабочий вариант прайса, их нужно свести с реальным.

4. **Положить изображения** в `img/` по именам из `img/README.md`. Пока
   файла нет, на его месте стоит блок-заглушка с подписью; как только файл
   появится, картинка проявится, а подпись исчезнет. Пути относительные
   (`img/case-gbo.png`), поэтому сайт одинаково работает и в корне домена,
   и в подпапке.

## Дизайн-система

**Палитра.** Восемь переменных в `:root` файла `style.css`, других цветов в
проекте нет: полупрозрачные тени и фокус берут значения от `--fg` и
`--accent`. Акцент `#0369A1` занимает не более 5 процентов экрана: кнопки,
одно слово в заголовке первого экрана, подчёркивание активного пункта меню,
галочки в списках и кольцо фокуса.

На тёмной плоскости `--dark` вторичный текст использует `--border`, а не
`--muted`: `--muted` на тёмном даёт контраст 2.4:1 и проваливает AA.

**Шрифт.** Golos Text, одно семейство, иерархия строится весом и кеглем.
Выбран вместо Inter: нарисован под кириллицу, поэтому русский текст не
выглядит вторичным к латинице.

**Шкала.** h1 `clamp(34px … 56px)`, h2 `clamp(26px … 40px)`, body 17px
(16px на мобильном), мера строки 65ch для прозы и 34rem для лидов.
Все вертикальные отступы кратны 8px, между секциями `clamp(56px, 8vw, 112px)`.

**Форма элементов.** Одно правило на весь проект: кнопки и поля 8px,
карточки и медиа 12px, модалка 16px.

**Брейкпоинты.** 1200 / 900 / 640. Мобильная версия пересобрана: карточки в
одну колонку, процесс разворачивается по вертикали с линией слева, кнопки на
всю ширину, меню на весь экран.

**Движение.** Появление секций через `IntersectionObserver`, 400ms,
`opacity` и `translateY`. Контент видим по умолчанию: анимация включается
только при наличии класса `js` на `<html>` и отсутствии
`prefers-reduced-motion`. Скролл-слушателей нет, состояние шапки тоже
определяет `IntersectionObserver` по маячку в начале документа.

## Доступность

Семантические теги и лендмарки, ссылка «Перейти к содержимому» первым
табом, видимый фокус 2px на всех интерактивных элементах (белый на тёмной
плоскости), корректная иерархия заголовков, `alt` у всех изображений,
`label` у всех полей формы. Аккордеон построен на нативной паре
`details/summary`, поэтому ручные ARIA-атрибуты ему не нужны и не
добавлены. Мобильное меню закрывается по Escape, возвращает фокус на
бургер и помечает `main` атрибутом `inert`.

Контраст проверен: основной текст 7.2:1, текст на кнопке 5.9:1, текст в
тёмном блоке 14.5:1, подписи плейсхолдеров 6.2:1.

## Локальный запуск

Любой статический сервер, сборка не нужна:

```bash
npx http-server -p 8000 .
```
