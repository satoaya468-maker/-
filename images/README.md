## Как подставить фото

Внутри блока-плейсхолдера уже готова разметка — достаточно добавить `img`
рядом с подписью:

```html
<div class="ph">
  <img src="./images/hero-main.jpg" alt="Мастер меняет колесо в боксе" loading="lazy">
  <span>ФОТО: hero-main.jpg — тёмная мастерская, работа с диском</span>
</div>
```

Изображение растянется по блоку (`object-fit: cover`) и перекроет подпись.
Пропорции задаются классами `ph-43`, `ph-34`, `ph-11`, `ph-169` либо сеткой
галереи. Фото желательно тёмные, без цветных акцентов — палитра сайта
строго чёрно-белая.
