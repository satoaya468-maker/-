# Фото и видео мастерской

## Что стоит сейчас

Все кадры ниже — стоп-кадры из присланного ролика `video/hero-loop.mp4`
(мастер работает пневмогайковёртом). Сюжет у них один, поэтому по-хорошему
их стоит заменить разными снимками мастерской.

| Файл | Что на кадре | Где используется |
|---|---|---|
| `hero-poster.jpg` | Постер для видео в hero | index.html |
| `work-1.jpg` | Мастер у колеса, общий план | index.html — галерея |
| `work-2.jpg` | Работа с колесом | uslugi.html, o-nas.html |

## Чего не хватает

`workshop-1.jpg` — интерьер бокса, чистое пространство. Слот стоит
плейсхолдером в галерее на `o-nas.html`.

## Как заменить фото

Просто положите свой файл с тем же именем в эту папку — разметку править не
нужно. Если имя другое, поменяйте `src` у нужного `img`:

```html
<div class="ph">
  <img src="./images/work-1.jpg" alt="Мастер меняет колесо" loading="lazy">
  <span>ФОТО: work-1.jpg — снятие колеса</span>
</div>
```

Подпись в `span` — подложка: она видна, только пока фото не загрузилось.

Снимки могут быть цветными: на сайте они обесцвечиваются через CSS
(`filter: grayscale(1)`), палитра остаётся строго монохромной. Размер по
длинной стороне 1400–1800 px, JPEG — этого хватает.

## Видео

`video/hero-loop.mp4` (H.264, 1280×720, 11 с, без звука) и
`video/hero-loop.webm` — тот же ролик для браузеров без H.264. Петля играет
без звука в hero главной, у неё есть кнопка паузы, она останавливается при
уходе со страницы и не запускается, если в системе включено «уменьшить
движение».

Чтобы поменять ролик, перекодируйте свой в такие же файлы:

```bash
ffmpeg -i исходник.mp4 -an -vf scale=1280:-2 -c:v libx264 -crf 27 \
       -movflags +faststart video/hero-loop.mp4
ffmpeg -i video/hero-loop.mp4 -an -c:v libvpx-vp9 -crf 36 -b:v 0 \
       video/hero-loop.webm
ffmpeg -ss 1.2 -i исходник.mp4 -frames:v 1 -vf scale=1600:-2 \
       images/hero-poster.jpg
```
