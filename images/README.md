# Фото для сайта «Юла»

Положите файлы в эту папку **с точно такими именами** — они подставятся сами,
цветные плейсхолдеры исчезнут. Ничего в коде менять не нужно.

Формат: JPG, ширина 1600–2400 px, вес до ~500 КБ на файл.

## Видео

Лежит в папке `../video/`:

- `hero.mp4` — 1280 px, для десктопа;
- `hero-mobile.mp4` — 720 px, лёгкая версия.

Чтобы заменить hero-видео на своё, перекодируйте его в те же имена файлов
(без звука, до ~2 МБ) и обновите `hero-poster.jpg`.
