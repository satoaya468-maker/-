# Dp line — витрина интернет-магазина автозапчастей (Магнитогорск)

Фронтенд-витрина на моковых данных: статический HTML/CSS/JS без сборки.
Деплой — заливкой содержимого папки `dp-line/` на хостинг (reg.ru + ISPmanager).

## Дизайн-направление

«Каталожный лист» — светлая инженерная витрина: бумага и тушь, точные
линии, моноширинный шрифт (JetBrains Mono) для артикулов, цен и сроков,
брендовый градиент dp (циан → фиолет → маджента) дозированно: топ-линия,
логотип, бейдж «выгодно». Иерархия карточки: цена → срок → бренд.
Mobile-first. Альтернативные направления главного экрана — в `variants/`
(вариант B — тёмный «Терминал», вариант C — светлая «Витрина»).

## Структура

```
index.html      — главная: поиск (артикул / марка-модель / VIN-заглушка), категории, топ, шаги
search.html     — результаты: сравнение предложений поставщиков, сортировка цена/срок, «в наличии»
product.html    — карточка: спецификация, все предложения, аналоги/кроссы
cart.html       — корзина: количество, пункт самовывоза (без полей доставки)
checkout.html   — оформление: имя + телефон (+ комментарий), самовывоз, экран успеха
css/main.css    — дизайн-система
js/data.js      — МОК-данные: 44 позиции, 6 «поставщиков», у части позиций 2–4 предложения
js/api.js       — API-слой: все страницы ходят только через DP.api.*
js/ui.js        — общий UI: иконки (единый SVG-набор), корзина (localStorage), шапка/подвал
variants/       — три варианта направления главного экрана (для выбора с клиентом)
```

## Подключение реального бэкенда

UI не знает про моки: страницы вызывают `DP.api.searchParts(params)`,
`DP.api.getPart(id)`, `DP.api.submitOrder(order)` и т.д. Чтобы перейти на
реальные интеграции (30–40 поставщиков, TecDoc):

1. в `js/api.js` заменить реализации функций на `fetch('/api/…')`,
   сохранив форму ответа (`{ items, analogs, total, offersTotal }` и т.п.);
2. удалить `js/data.js` и его `<script>`-подключения;
3. вкладку «По VIN» на главной включить после подключения TecDoc.
