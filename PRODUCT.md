# Ракета — демо интернет-магазина электроники

**Клиент:** магазин электроники «Ракета», Магнитогорск (пр. Карла Маркса, 92, рейтинг 4.9 / 176 оценок на 2ГИС).
**Регистр:** brand + commerce. Дизайн продаёт: премиально, минималистично, конверсионно.
**Референсы:** Apple.com, re:Store. Анти-референсы: DNS, Ситилинк, Эльдорадо (баннерный шум).

## Статус
Демо-версия перед подключением реальных данных: каталог захардкожен в `js/data.js`,
оплата и формы — заглушки (console.log), 54-ФЗ / эквайринг / API поставщиков — следующий этап.

## Дизайн-система
- **Шрифт:** Manrope (variable 200–800, self-hosted, кириллица + латиница), система как fallback.
- **Палитра:** фон `#fff`, поверхности `#f5f5f7`, чернила `#0e0e12`, вторичный `#6a6a74`,
  акцент (CTA) `#0051e6`, скидки `#d81f33`, успех `#0a8a50`. Тёмные витринные тайлы `#0c0c11`.
- **Радиусы:** кнопки pill (999), карточки 18, тайлы 22, инпуты 12. Тени мягкие, тонированные.
- **Моушн:** сдержанный. 160–260ms, cubic-bezier(.23,1,.32,1), только transform/opacity,
  reveal-on-scroll один раз, prefers-reduced-motion уважается.
- **Товарная графика:** генерируемые SVG-иллюстрации устройств (`js/art.js`) на тайлах
  `#f5f5f7` — целостная витрина без стоковых фото; заменяются на реальные фото при
  подключении каталога.

## Структура
index / catalog / product / cart (+checkout) / sales / delivery / warranty / contacts —
статические HTML, общие header/footer рендерит `js/app.js`, каталог — `js/data.js`.
Корзина в localStorage. Работает с file:// и на любом хостинге (reg.ru / ISPmanager).

## Конверсионные механики
Апсейл «С этим товаром покупают», комплекты со скидкой, рекомендации в корзине,
витрина флагмана в категории, «Купить в 1 клик», промокод РАКЕТА10, блоки доверия.
