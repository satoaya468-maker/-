# Шрифты

Onest и Unbounded распространяются по SIL Open Font License 1.1 —
тексты лицензий лежат рядом (`OFL-Onest.txt`, `OFL-Unbounded.txt`).

Файлы в этой папке — сабсеты, собранные из оригинальных TTF с Google Fonts:

- **Onest** 400/500/700/800 — кириллица, базовая латиница, цифры,
  типографские знаки. Основной текст и заголовки.
- **Unbounded** 700 — только цифры и несколько знаков (`₽ % + − , . /`).
  Используется исключительно для крупных чисел: цены, экономия,
  окупаемость, номера шагов.

Итого 72 КБ на все пять начертаний вместо 372 КБ у полных субсетов
Google Fonts.

Пересобрать (нужен `pyftsubset` из `fonttools`):

```bash
pyftsubset onest-400.ttf --output-file=onest-400.woff2 --flavor=woff2 \
  --unicodes="U+0020-007E,U+00A0,U+00AB,U+00BB,U+00B0,U+00D7,U+2010-2015,U+2018-201F,U+2020-2022,U+2026,U+2030,U+2039-203A,U+2116,U+2212,U+20BD,U+2192,U+2193,U+2191,U+2190,U+2713,U+0400-045F,U+0490-0491,U+04E2-04E3" \
  --layout-features=kern,liga,calt,tnum --no-hinting --desubroutinize
```
