# Чат-виджет «Менеджер базы»

Бэкенд для чата на странице `stroy-baza-74.html`. Ключ Claude API живет только здесь,
в браузер он не попадает.

## Запуск

```bash
cd server
npm install
ANTHROPIC_API_KEY=sk-ant-... node chat-server.mjs
# сайт: http://localhost:8080/
```

Ключ можно положить в `.env` вашего процесс-менеджера (образец в `.env.example`)
или передать через systemd, Docker, панель хостинга. В коде он не хранится.

## Эндпоинты

| Метод и путь     | Что делает                                                                 |
| ---------------- | -------------------------------------------------------------------------- |
| `POST /api/chat` | История переписки уходит в Claude API, обратно возвращается `{ reply }`      |
| `POST /api/lead` | Телефон из чата, сейчас пишется в лог: место для интеграции с CRM            |
| `GET /*`         | Статика сайта из папки выше                                                  |

## Поведение без ключа

Если `ANTHROPIC_API_KEY` не задан, `/api/chat` отвечает `503 { "error": "no_key" }`.
Виджет это ловит и переключается на встроенную заглушку: она знает прайс склада,
считает объемы по тем же формулам, что калькулятор на странице, рассказывает про
доставку и оплату и так же просит телефон. Сайт остается рабочим, просто ответы
становятся шаблонными. То же самое происходит на чистой статике, где эндпоинта нет вовсе.

## Модель и параметры

- Модель: `claude-opus-5`.
- `output_config.effort: "low"` - чат короткий, низкое усилие держит ответ быстрым и дешевым.
- `max_tokens: 1024` - ответы в 2-4 предложения по инструкции промпта.
- Системный промпт кэшируется (`cache_control: ephemeral`): он одинаковый для всех диалогов.
- Включены серверные fallback'и (`fallbacks: "default"`): если классификатор отклонит
  запрос, тот же вызов доигрывается на запасной модели, и диалог не обрывается.

Промпт и прайс лежат в `prompt.mjs`. Цены там дублируют витрину страницы: правите
прайс - правьте оба места (в заглушке виджета массив `CHAT_PRICES`).

## Защита

- Ключ только на сервере, в ответах клиенту его нет.
- Лимит 30 запросов на IP за 10 минут.
- История обрезается до 20 сообщений по 1200 символов, тело запроса до 64 КБ.
- Статика отдается только из папки сайта, выход за нее закрыт.

Перед публикацией стоит добавить домен в CORS (сейчас запросы идут с того же
origin), поставить сервис за reverse proxy с HTTPS и завести отдельный ключ
с ограниченным лимитом расходов в консоли Anthropic.

## Развертывание на serverless

Функцию `handleChat` можно перенести в `api/chat.js` (Vercel, Netlify) почти без
правок: тело запроса и ответ те же, меняется только сигнатура обработчика.
Путь `/api/chat` на клиенте менять не нужно.
