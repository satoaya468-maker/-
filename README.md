# Ракета — демо интернет-магазина электроники (Магнитогорск)

Многостраничная демо-версия магазина «Ракета» (пр. Карла Маркса, 92).
Премиум-минимализм в духе Apple / re:Store: воздух, крупные товарные визуалы,
одна акцентная кнопка. Чистый HTML/CSS/JS без сборки: открывается двойным
кликом по `index.html` (работает с file://) и загружается на любой хостинг
(reg.ru / ISPmanager) как есть.

## Страницы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Главная: hero, категории, хиты, промо-тайлы, распродажа, новинки, блок доверия, визит в магазин |
| `catalog.html` | Каталог: фильтры (цена, бренд, скидка), сортировка, пагинация, витрина флагмана категории |
| `product.html` | Карточка: галерея, цена и рассрочка, «В корзину» и «Купить в 1 клик», комплект со скидкой, «С этим товаром покупают», характеристики, отзывы, похожие |
| `cart.html` | Корзина + оформление: количество, промокод `РАКЕТА10`, скидки за комплекты, рекомендации, способы получения и оплаты, экран успеха |
| `sales.html` | Акции: баннер промокода, товары со скидкой, комплектные предложения |
| `delivery.html` | Доставка и оплата + FAQ |
| `warranty.html` | Гарантия и сервисный центр + FAQ |
| `contacts.html` | Адрес, часы, телефон, схема проезда, форма обратной связи |

## Архитектура

- `js/data.js` — весь каталог (55 товаров, 9 категорий, отзывы, комплекты).
  Плейсхолдер: структура повторяет будущий API поставщика, замена данных
  не трогает вёрстку.
- `js/art.js` — генератор товарной SVG-графики (30 типов устройств).
  При подключении реального каталога заменяется на фотографии товара.
- `js/app.js` — шапка/подвал, корзина (localStorage), каталог, карточка,
  оформление. Формы пишут в `console.log` — интеграция (Telegram/CRM,
  эквайринг + 54-ФЗ) на следующем этапе.
- `css/style.css` — дизайн-система (токены в `:root`).
- `assets/fonts/` — self-hosted Manrope (кириллица + латиница).

## Перед запуском в прод

1. Заменить данные `js/data.js` на реальный фид, SVG-арты на фото.
2. Подключить приём заказов (Telegram-бот или CRM) вместо console.log.
3. Эквайринг + онлайн-касса (54-ФЗ) в `cart.html`.
4. Убрать `noindex` из всех страниц, добавить домен, sitemap, метрику.
5. Реальные реквизиты ИП в `contacts.html` и футере.
