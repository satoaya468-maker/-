# EasyLead

Одностраничный сайт агентства EasyLead. Чистые HTML, CSS и JS, без сборки:
содержимое репозитория кладётся на любой хостинг как есть.

Задача сайта: превращать платный трафик в заявки. Человек с рекламного
объявления должен за первые секунды понять, что мы делаем, сколько это стоит
и как оставить заявку. Заявка состоит из двух полей и уходит в Telegram.

## Что нужно сделать перед запуском

### 1. Контакты

Откройте `js/config.js` и впишите свои данные:

```js
phone:     '+7 900 123-45-67',   // как показывать
phoneHref: '+79001234567',       // как звонить
telegram:  'https://t.me/ваш_аккаунт',
```

Эти значения подставляются во все ссылки на странице: в герой, в финальный
блок, в подвал и в нижнюю панель на телефоне.

### 2. Подключение формы

Пока `endpoint` в `js/config.js` пустой, форма честно говорит посетителю, что
она не подключена, и показывает телефон и Telegram. Ложного «отправлено» не
будет никогда.

Чтобы заявки приходили в Telegram:

1. Создайте бота у `@BotFather`, получите токен.
2. Напишите боту любое сообщение, затем откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите там `chat.id`.
3. Разверните обработчик из `worker/telegram-lead.js` на Cloudflare Workers
   (бесплатного тарифа хватает с запасом):

   ```bash
   npm create cloudflare@latest easylead-lead
   # замените содержимое src/index.js на worker/telegram-lead.js
   npx wrangler secret put TELEGRAM_BOT_TOKEN
   npx wrangler secret put TELEGRAM_CHAT_ID
   npx wrangler deploy
   ```

4. В `worker/telegram-lead.js` впишите свой домен в `ALLOWED_ORIGINS`.
5. Полученный адрес воркера положите в `endpoint` в `js/config.js`.

Токен бота живёт в секретах воркера и в браузер не попадает. Класть токен
прямо в JS на сайте нельзя: его заберут в первый же день.

### 3. Домен

Замените `example.com` на свой домен в трёх местах: `index.html`
(теги `canonical` и `og:*`), `robots.txt`, `sitemap.xml`.

### 4. Проверьте цифры

В коде помечены комментарием `ПРОВЕРЬ` места, где стоят данные со слов
владельца, а не проверенные факты:

- вилка `30 000 до 70 000 ₽` за сайт в блоке цен;
- домен в мета-тегах, `robots.txt` и `sitemap.xml`;
- список доменов в `ALLOWED_ORIGINS` воркера.

Картинки для соцсетей (`og:image`) пока нет: файл
`assets/img/easylead-og.png` нужно добавить, иначе ссылка на сайт в мессенджере
будет без превью.

## Структура

```
index.html                 страница целиком
css/fonts.css              локальные шрифты
css/easylead.css           дизайн-система и вёрстка
js/config.js               единственный файл с настройками
js/easylead.js             формы, маска телефона, панель заявок, анимации
worker/telegram-lead.js    обработчик формы для Cloudflare Workers
assets/fonts/              Onest и JetBrains Mono, подмножества cyrillic и latin
DESIGN.md                  токены, шкалы и запреты проекта
PRODUCT.md                 для кого сайт и что считается успехом
```

## Решения, которые стоит знать перед правками

- **Шрифты локальные.** Ни одного запроса к чужому CDN: для платного трафика
  важен каждый лишний round trip. Подключены только кириллица и латиница,
  115 КБ на всё.
- **Ни одного слушателя `scroll`.** Прилипающая шапка, появление секций и
  нижняя панель на телефоне построены на `IntersectionObserver`.
- **Без JavaScript страница видна целиком.** Стартовое смещение для анимаций
  включается классом `.js`, который ставится синхронно в `<head>`.
- **Панель заявок в герое не макет.** Она показывает то, что посетитель прямо
  сейчас печатает в форме, и меняет состояние на «доставлено» после отправки.
  Если будете её править, не превращайте в декорацию: она работает как
  подтверждение, что форма живая.
- **Монохром без исключений.** Ошибки и успех различаются иконкой и текстом,
  а не цветом. Цветной акцент сломает всю систему, описанную в `DESIGN.md`.
- **Никаких выдуманных кейсов, логотипов, отзывов и цифр.** Это осознанное
  решение, а не недоделка: секция «У нас нет витрины с кейсами» построена
  именно на этом.
