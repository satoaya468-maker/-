# Автостекло74 — сайт сервиса автостёкол (Магнитогорск)

Многостраничный продающий сайт для сервиса «Автостекло74»:
замена лобовых, боковых и задних стёкол, ремонт сколов и трещин,
полировка фар. Чистый HTML/CSS/JS без сборки — загрузите содержимое
репозитория на любой хостинг.

Продающие элементы: липкая панель «Позвонить / WhatsApp» на мобильных,
телефон в каждой секции, виджет оценки (5 звёзд ведут на страницу
отзывов в 2ГИС, ниже пяти — жалоба владельцу в WhatsApp). Кнопки
WhatsApp ведут на wa.me/79030913333 — если у бизнеса нет WhatsApp
на этом номере, уберите их в `.callbar`, hero и виджете оценки.

## Страницы

```
index.html     — главная: hero с видео, услуги, живая линия отзывов,
                 цифры, процесс замены, CTA
uslugi.html    — услуги и цены с подробностями по каждой позиции
otzyvy.html    — отзывы (рейтинг 5,0 на 2ГИС) со ссылкой на первоисточник
kontakty.html  — контакты, часы работы, карта, маршрут в 2ГИС
```

## Структура

```
css/style.css   — дизайн-система (графит + кость + стеклянная мята)
js/main.js      — меню, reveal-анимации, лента отзывов, статус «открыто»
assets/img/     — фотографии (скачивает CI, см. ниже)
assets/video/   — hero-видео (скачивает CI)
```

## Медиа

Фотографии и hero-видео — со стока Pexels (свободная лицензия,
можно использовать в коммерческих проектах без указания авторства).
Workflow `.github/workflows/fetch-assets.yml` скачивает их при первом
пуше и коммитит в ветку. Если GitHub Actions выключен, запустите его
вручную: Actions → Fetch media assets → Run workflow.

Пока файлы не скачаны, сайт полностью рабочий: каждая картинка
подгружается напрямую с CDN Pexels (атрибут `data-fallback`),
а hero показывает постер вместо видео.

Чтобы заменить видео на собственную съёмку процесса установки —
положите файл в `assets/video/hero.mp4` (mp4, 1600px по ширине,
10–15 секунд, без звука).

## Фотографии работ «до/после»

Секция «Наши работы» на главной ждёт четыре файла в `assets/img/`:

```
work-bmw-do.jpg      — BMW X5, старое стекло демонтировано
work-bmw-posle.jpg   — BMW X5, новое стекло вклеено
work-xray-do.jpg     — Lada XRAY, проём без стекла
work-xray-posle.jpg  — Lada XRAY, новое стекло установлено
```

Пока файлов нет, секция автоматически скрыта — сайт выглядит целым.
Положите фотографии с этими именами (jpg, вертикальные ~960×1280) —
и секция появится сама. Перед загрузкой замажьте госномера машин.

Загрузить прямо через GitHub: откройте
https://github.com/satoaya468-maker/-/upload/claude/autoglass-website-sjitg5/assets/img
перетащите четыре файла и нажмите «Commit changes».

## Перед публикацией

1. Замените `https://avtosteklo74-mgn.ru/` на реальный домен в
   `index.html`, `uslugi.html`, `otzyvy.html`, `kontakty.html`,
   `robots.txt` и `sitemap.xml`.
2. Проверьте цены на странице услуг — сейчас указаны ориентировочные
   («от»), уточните их у владельца.
3. Имена авторов отзывов на главной и в `otzyvy.html` — проверьте по
   странице на 2ГИС (тексты взяты из реальных отзывов).
