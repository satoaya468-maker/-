# Ульяна · Груминг — сайт студии груминга в Магнитогорске

Многостраничный сайт частного грумера Ульяны Филипцевич. Чистый HTML/CSS/JS,
без сборки: содержимое репозитория можно положить на любой статический хостинг
как есть.

> В этом же репозитории лежит более ранний проект «Спектр» —
> `spektr-landing.html`, `spektr.html`, `css/`, `js/`, `assets/`, `README-spektr.md`.
> Он не тронут, просто уступил имя `index.html`.

## Структура

```
index.html        — главная: видео-hero, «обо мне», услуги, галерея, отзывы, CTA
uslugi.html       — четыре развёрнутых блока услуг
ceny.html         — прайс (собаки / кошки / дополнительно)
otzyvy.html       — отзывы + фильтр по звёздам + приватная обратная связь
contakty.html     — адрес, мессенджеры, карта, форма записи

styles.css        — единая дизайн-система для всех пяти страниц
app.js            — виджет записи, фильтр отзывов, формы, тосты, анимации

grooming-hero.mp4 — фоновое видео hero (1920×1080, ~2,9 МБ)
media/            — фотографии, мобильная версия видео, постер, фавиконка
```

Шапка и футер намеренно скопированы в каждый файл — их правят руками.
Общего у страниц только `styles.css` и `app.js`.

страница не разъезжается, если CDN недоступен.

## Фотографии — что заменить перед сдачей клиенту

Все изображения в `media/` — кадры из видео, которое прислала Ульяна:
один сеанс стрижки йоркширского терьера, обрезанные под разные форматы и
приведённые к тёплой палитре сайта. Это настоящая её работа, но это один
питомец, поэтому блок «До и после» стоит заменить на реальные фото из
её 2ГИС и ВК.

Что менять и где:

| Файл | Где используется |
|---|---|
| `media/master-hands.jpg` | index.html — секция «Лично» |
| `media/portrait-yorkshire.jpg`, `detail-clipper.jpg`, `standing-vertical.jpg`, `looking-up.jpg`, `full-body.jpg`, `profile-vertical.jpg` | index.html — галерея «До и после» |
| `media/studio-wide.jpg`, `detail-clipper.jpg`, `head-clipper.jpg`, `paws-table.jpg` | uslugi.html — четыре услуги |
| `media/og-cover.jpg` | превью при отправке ссылки (1200×630) |
| `media/hero-poster.jpg` | первый кадр hero-видео до автоплея |

У каждого `<img>` проставлены `width`/`height` — при замене обновите их под
реальный размер файла, иначе поедет вёрстка при загрузке.

## Заявки: Telegram

Формы и виджет пока пишут заявку в консоль. Чтобы заявки приходили в Telegram,
заполните в начале `app.js`:

```js
var TOKEN   = 'YOUR_BOT_TOKEN';   // токен бота от @BotFather
var CHAT_ID = 'YOUR_CHAT_ID';     // id чата Ульяны или группы
```

Пока значения не заменены, `notifyTelegram()` ничего не отправляет и пишет
подсказку в консоль. Через неё идут все три точки входа: виджет (после ввода
телефона), форма записи на `contakty.html` и приватная обратная связь
на `otzyvy.html`.

> Токен бота в клиентском JS виден любому посетителю. Для боевого запуска
> заявку лучше отправлять на свой эндпоинт, а он уже пусть ходит в Telegram.

## Оценка звёздами

Блок с пятью звёздами стоит на главной (в секции отзывов) и на `otzyvy.html`.
Логика сознательно несимметричная:

- **5 звёзд** — открывается 2ГИС, отзыв уходит в публичную карточку;
- **1–4 звезды** — вместо этого открывается форма обратной связи. Обращение
  не публикуется: оно уходит лично Ульяне, чтобы вопрос решался в личной
  переписке, а не в публичной ленте.

Разметка одинаковая на обеих страницах: контейнер с `data-rating="<id панели>"`,
внутри пять кнопок `.rate__star` с `data-value`, рядом `[data-rate-hint]`.
Панель с формой помечается `data-feedback-form`, оценка попадает в скрытое
поле `name="rating"`. Чтобы добавить блок на любую другую страницу, достаточно
скопировать эту разметку — `app.js` подхватит её сам.

## Видео

Четыре файла, все перекодированы из исходных 4K/30 МБ:

| Файл | Размер кадра | Вес |
|---|---|---|
| `grooming-hero.mp4` | 1920×1080 H.264 | 2,9 МБ |
| `media/grooming-hero.webm` | 1920×1080 VP9 | 3,7 МБ |
| `media/grooming-hero-mobile.mp4` | 960×540 H.264 | 0,75 МБ |
| `media/grooming-hero-mobile.webm` | 960×540 VP9 | 0,97 МБ |

Размер (мобильный / десктопный) выбирает `app.js` — атрибут `media` у `<source>`
браузеры трактуют по-разному, и телефоны успевали скачать обе версии.
Формат (mp4 / webm) выбирает уже сам браузер по `type`: Chrome, Safari и Яндекс
берут mp4 и до webm не доходят, webm нужен сборкам без проприетарных кодеков.

Видео ставится на паузу, когда уходит из вида или вкладка неактивна.
При `prefers-reduced-motion` и при включённой экономии трафика оно
не загружается вообще — остаётся постер `media/hero-poster.jpg`.

## Проверено

- Chromium, ширины 320 / 375 / 1440 — горизонтального скролла нет
- Сценарий виджета целиком, включая неполный номер телефона
- Фильтр отзывов, форма обратной связи, форма записи — с тостами
- `prefers-reduced-motion`: анимации и автоплей отключаются
