# dp line — автозапчасти, Магнитогорск

Главная страница интернет-магазина автозапчастей: поиск по VIN-коду и
артикулу, выбор филиала, популярные категории и корзина. Один файл
`index.html` без сборки и внешних скриптов — загрузите его на любой хостинг.

## Стек

- **HTML + Tailwind CSS** — стили скомпилированы и встроены прямо в файл
  (CDN не используется, страница открывается мгновенно);
- **чистый JavaScript** — без библиотек и фреймворков.

## Что работает без бэкенда

- распознавание VIN (17 символов) и артикула в строке поиска;
- демо-выдача результатов после нажатия «Найти» (помечена бейджем «демо»);
- выбор филиала: дропдаун в хедере синхронизирован с картой и
  запоминается в localStorage;
- компактный поиск в липкой шапке — запускает тот же поиск из любой
  точки страницы;
- рабочая корзина: товары из блока «Часто покупают» добавляются,
  считаются и хранятся в localStorage (оформление заказа — демо);
- баннеры спецпредложений с модальной формой записи в сервис
  (заявка пока никуда не отправляется — см. комментарий «Демо-режим»);
- чат «Помощь эксперта» в углу экрана с демо-диалогом и
  распознаванием VIN;
- горячая клавиша `/` — фокус на поиск.

## Подключение реального поиска

Форма отправляет `GET /search?q=...`. В `index.html` найдите комментарий
«Демо-режим» в блоке `<script>`: замените `setTimeout` на запрос к вашему
API и передавайте его ответ в `renderResults`.
