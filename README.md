# dp line — автозапчасти, Магнитогорск

Плотная B2B-витрина магазина автозапчастей: тёмный монолитный хедер с
поиском по названию/артикулу/VIN, левое меню каталога, акционный баннер,
популярные товары с корзиной и чат «Помощь эксперта». Один файл
`index.html` без сборки и внешних скриптов — загрузите его на любой хостинг.

## Стек

- **HTML + Tailwind CSS** — стили скомпилированы и встроены прямо в файл
  (CDN не используется, страница открывается мгновенно);
- **чистый JavaScript** — без библиотек и фреймворков.

## Что работает без бэкенда

- поиск в хедере: распознавание VIN (17 символов) и артикула,
  выпадающая демо-выдача (помечена бейджем «демо»);
- выбор филиала — запоминается в localStorage;
- рабочая корзина: товары добавляются, считаются и хранятся в
  localStorage, боковая панель со списком и итогом
  (оформление заказа — демо);
- чат «Помощь эксперта» с демо-диалогом и распознаванием VIN;
  кнопка «Записаться» на баннере открывает этот чат;
- горячая клавиша `/` — фокус на поиск.

## Подключение бэкенда

Точки интеграции помечены в `index.html` комментариями «Демо-режим»:
выдача поиска (`renderResults`), каталог товаров (`PRODUCTS`),
оформление заказа и сообщения чата.
