# Балкон для души — премиальный лендинг

Чистый, минималистичный одностраничный сайт для компании **«Балкон для души»**
(Магнитогорск): отделка и остекление балконов под ключ. **Светлая премиальная
тема** (тёплый белый + золото), сплит-герой с анимированным видео. Без сборщиков
и зависимостей — обычные HTML/CSS/JS. Загрузите содержимое репозитория на любой
хостинг (GitHub Pages, Netlify, обычный shared-хостинг) — и сайт работает.

## Фото работ (важно)

Галерея «Наши работы» рассчитана на ваши реальные фото. Положите 5 снимков в
`assets/works/` с именами `work-1.jpg … work-5.jpg` (см. `assets/works/README.md`).
Пока файлов нет, в галерее автоматически показываются похожие по стилю
изображения-заглушки — сайт не выглядит пустым, а с добавлением фото они
заменяются на ваши.

## Медиа

Hero-видео и фотографии работ сгенерированы в **Higgsfield AI** под фирменный
стиль (графит + золото, как на логотипе). По умолчанию сайт подключает их
напрямую с CDN Higgsfield — он отдаётся публично, поэтому страница выглядит
завершённой сразу в любом браузере. На каждый блок предусмотрен премиальный
градиент-fallback: если картинка не загрузится, дырки в дизайне не будет.

### Самостоятельный хостинг медиа (рекомендуется перед запуском)

Чтобы не зависеть от стороннего CDN, скачайте медиа к себе и перепишите ссылки
на локальные:

```bash
./scripts/localize-media.sh
```

Скрипт скачает все картинки и видео в `assets/media/` и заменит ссылки на CDN в
`index.html` на локальные. То же самое можно запустить через GitHub Actions:
вкладка **Actions → Localize media → Run workflow**.

## Чат-виджет

Виджет полностью клиентский (без бэкенда). Он отвечает на типовые вопросы
(стоимость, сроки, остекление, утепление, объединение, электрика, гарантия,
под ключ) и предлагает связаться через WhatsApp, ВКонтакте или звонок —
с уже подставленным текстом обращения. Логика и тексты — в `js/chat.js`,
номера и ссылки заданы константами в начале файла.
