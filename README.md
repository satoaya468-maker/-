# Мастер на час — Магнитогорск

Многостраничный сайт частного мастера по вызову (мелкий бытовой ремонт под ключ)
в Ленинском районе Магнитогорска. Чистый HTML/CSS/JS без сборки — загрузите
содержимое репозитория на любой хостинг (рассчитано на reg.ru).

Слоган: **«Выполню работу под ключ: вы показываете — я решаю».**

## Структура

```
index.html        — Главная: hero с мастером, «под ключ», услуги, доверие, отзывы
uslugi.html       — Услуги подробно (сантехника, электрика, сборка, навеска, ремонт)

kontakty.html     — Телефон, email, VK, район выезда, часы, ИНН

js/main.js        — меню, карусель отзывов, появление при скролле, отправка формы
send.php          — приём заявки и уведомление в Telegram (токен только на сервере)
```

Иконки — инлайновый SVG-спрайт в каждой странице (работает и на хостинге, и в
локальном предпросмотре, без внешних запросов). Иллюстрация мастера —
`assets/img/master.svg` (нарисована вручную, не сток).

## Приём заявок в Telegram

Форма отправляет заявку на `send.php`, который пересылает её в Telegram. **Токен
бота хранится только на сервере** (в client-side JS его класть нельзя). До
подключения бота форма работает в демо-режиме: показывает подтверждение клиенту
и пишет данные в консоль браузера — можно показывать заказчику.

Как подключить (5 минут):

1. В Telegram: **@BotFather** → `/newbot` → получите **токен**.
2. Напишите своему боту любое сообщение (иначе он не сможет вам отвечать).
3. Узнайте **CHAT_ID**: откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найдите `"chat":{"id": ...}`.
4. Впишите `TG_BOT_TOKEN` и `TG_CHAT_ID` в начале `send.php` (или задайте их
   переменными окружения на хостинге — безопаснее).
5. Готово. reg.ru поддерживает PHP, дополнительный сервер не нужен.

Если хостинг совсем без PHP — форму можно перенастроить на любой существующий
Telegram-бот/webhook агентства (эндпоинт задаётся атрибутом `action` у формы).

## Перед публикацией

1. Замените домен `https://master-mgn.ru/` на реальный — в `<link rel=canonical>`
   и OG-тегах каждой страницы, в `robots.txt` и `sitemap.xml`.
2. Заполните токен и chat_id в `send.php` (см. выше).
3. По желанию: добавьте в группу ВК фото реальных работ — на них ссылается
   страница отзывов.

## Локальный предпросмотр

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Открывать через локальный сервер (а не файлом `file://`) — так корректно
работают шрифты и относительные ссылки.

## Заметка для агентства: апсейл на GoHighLevel (не входит в сборку сайта)

Отдельный платный доп-пакет поверх сайта. Мастеру нужен свой sub-account GHL,
оплата отдельно от разработки. Что предложить соло-мастеру, который часто занят
руками и не берёт трубку:

- **Missed Call Text-Back** — авто-SMS клиенту при пропущенном звонке
  («Здравствуйте! Не смог ответить — я на выезде. Перезвоню, или напишите, что
  нужно»). Не теряем горячие заявки.
- **Автозапрос отзыва после вызова** — SMS/WhatsApp после отметки «заявка
  выполнена» с просьбой оставить отзыв на 2ГИС. Честный способ **реально
  нарастить** количество отзывов (вместо выдумывания новых).
- **Простой календарь записи на вызов** — клиент сам выбирает окно.

В основной сайт это намеренно не заложено — подаётся как отдельное предложение.
