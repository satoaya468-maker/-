# ГБО-АВТО сервис — сайт (Златоуст)

Многостраничный статический сайт автосервиса по установке и обслуживанию
газобаллонного оборудования. Собирается Eleventy в чистый HTML, который
встаёт на любой хостинг, включая шаред на reg.ru.

- Рантайм-зависимостей нет. JS ванильный, CSS рукописный.
- Шрифт один — Golos Text, самохостом, `.woff2`, сабсет под кириллицу и цифры. Никаких CDN.
- Все тексты, цены, услуги, отзывы и контакты — в `src/_data/*.json`.

## Запуск

```bash
npm install
npm start          # локальный сервер с автоперезагрузкой, http://localhost:8080
npm run build      # прод-сборка в dist/
```

Публикация: содержимое `dist/` кладётся в корень сайта на хостинге.

## Структура

```
src/
  _data/           данные: site, nav, services, calc, reviews, faq, steps, equipment
  _includes/
    layouts/       base.njk — единый каркас страницы, SEO, JSON-LD
    partials/      header, footer, facts, icons (спрайт Phosphor)
  pages/           страницы сайта
  index.njk        главная
  sitemap.njk      генерируется при сборке
  robots.njk       генерируется при сборке
assets/
  css/styles.css   дизайн-система целиком
  fonts/           Golos Text 400/500/600/700 — сабсет, 44 КБ на всё
  img/             предметная съёмка, иконки
  js/              app.js и модули (калькулятор, квиз, карусель)
worker/            релей заявок на Cloudflare Worker
dist/              результат сборки, в гит не коммитится
```

## Данные

Правки контента не требуют вёрстки — всё в `src/_data/`.

| Файл | Что внутри |
|---|---|
| `site.json` | название, телефоны, адрес, часы, мессенджеры, ссылки на 2ГИС, флаг `reviewGating`, адрес релея, ID Метрики |
| `nav.json` | список страниц; `inHeader: true` выводит пункт в шапку |
| `services.json` | услуги и цены; `lead` — ведущая услуга, `list` — остальные |
| `calc.json` | поля калькулятора, диапазоны, пресеты, сноска |
| `reviews.json` | **только реальные отзывы с 2ГИС**, см. предупреждение ниже |
| `faq.json`, `steps.json`, `equipment.json`, `promises.json` | контент секций |

### Отзывы — правило без исключений

В `reviews.json` попадают **только реальные отзывы с карточки 2ГИС, дословно**.
Придумывать отзывы, добавлять вымышленные имена или редактировать формулировки
нельзя: карточка 2ГИС публична, любой посетитель сверит текст за десять секунд,
а недостоверная реклама на сайте реальной компании — риск владельца сервиса.
Если отзывов мало, лента добирается слайдами другого типа (`cards` в том же
файле): рейтинг, состав гарантии, перечень документов.

## ⚠️ `reviewGating` — прочитайте до включения

В `src/_data/site.json` есть флаг:

```json
{ "reviewGating": false }
```

**`false` — значение по умолчанию, безопасное.** После любой оценки посетитель
видит благодарность и ссылку на 2ГИС. При оценке 1–3 дополнительно
раскрывается поле «Что пошло не так?», текст уходит владельцу в Telegram.
Ссылка на 2ГИС при этом остаётся доступна всем.

**`true` включает review gating:** оценки 4–5 ведут сразу на 2ГИС, а 1–3
уводятся только во внутреннюю форму.

Схема, при которой ссылка на площадку показывается только довольным клиентам,
называется review gating, и правила площадок отзывов её прямо запрещают. При
обнаружении карточка компании может получить предупреждающую пометку или
лишиться части отзывов. **Риск несёт владелец сервиса, а не разработчик
сайта.** Включайте флаг только осознанно.

## Заявки

Три источника — форма заявки, квиз-виджет, форма фидбэка из блока «Оцените
нас» — отправляют POST на релей (`worker/index.js`, Cloudflare Worker),
который дёргает Telegram Bot API.

**Токен бота и chat_id живут в переменных окружения Worker и никогда не
попадают в клиентский JS.** Адрес релея прописывается в `site.json` →
`relayUrl`.

## Перед публикацией

1. В `site.json` заменить `url` на боевой домен.
2. Указать `relayUrl` после развёртывания Worker и прописать боевой домен
   в CORS Worker.
3. Указать `metrikaId`, если нужна Яндекс.Метрика.
4. Удалить служебную страницу `src/pages/styleguide.njk` (дизайн-система,
   закрыта `noindex`).
