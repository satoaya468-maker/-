# Юла — детская игровая и студия праздников (Магнитогорск)

Многостраничный сайт с цифровым администратором от Ascend Systems.
Чистый HTML/CSS/JS без сборки — залейте содержимое репозитория на любой хостинг.

## Структура

```
index.html        — главная: hero с видео, пакеты, галерея, онлайн-бронь, отзывы, оценка
prazdniki.html    — 6 пакетов праздников подробно + индивидуальный формат
ceny.html         — прайс, что входит в пакет, допуслуги и доплаты
otzyvy.html       — отзывы с фильтром по звёздам (5★ → 2ГИС, ниже → форма Юле)
contakty.html     — адрес, карта, мессенджеры, форма быстрой брони
pravila.html      — порядок бронирования (8 шагов) и правила игровой (8 пунктов)

styles.css        — вся дизайн-система: фирменные цвета, типографика, адаптив
js/yula.js        — общий скрипт: меню, онлайн-бронь, toast-уведомления, чат-виджет
images/           — фото (см. images/README.md — список нужных файлов)
video/            — hero.mp4 (десктоп) и hero-mobile.mp4
```

Шапка и футер скопированы в каждый файл — правки в навигации нужно повторить
во всех шести страницах.

## Онлайн-бронирование

Заявку можно оставить тремя способами, все они ведут в одну функцию отправки:

1. кнопка «Забронировать» в шапке и в hero → модальное окно (любая страница);
2. форма на главной и на странице контактов;
3. чат-виджет «Юля» в правом нижнем углу.

После отправки показывается toast «ASCEND SYSTEMS · CRM» с номером телефона
заявителя.

## Подключение Telegram

В `js/yula.js` сверху:

```js
var TOKEN = 'YOUR_BOT_TOKEN';
var CHAT_ID = 'YOUR_CHAT_ID';
```

Пока стоят заглушки — заявка печатается в консоль браузера. Подставьте токен бота
и chat_id, и заявки начнут приходить в Telegram (`sendMessage`, `parse_mode: HTML`).

## Что нужно от клиента

1. **Фото** — 11 снимков + 6 фото пакетов, имена файлов в `images/README.md`.
   Пока фото нет, на их месте цветные плашки с подписью «Место для фото: …»;
   как только файл появится в папке, плашка исчезнет сама.
2. **Домен** — заменить `https://yula-mgn.ru/` в `robots.txt` и `sitemap.xml`.
3. **Проверить цифры** — второй аниматор указан как 2 500 ₽ (из правил игровой).
