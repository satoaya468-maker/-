# Спектр — сайт компании

Многостраничный сайт ООО «Спектр» (Магнитогорск): балконы, окна и комплексный
ремонт под ключ. Чистый HTML/CSS/JS без сборщиков — содержимое репозитория
загружается на любой хостинг как есть.

## Структура

```
index.html        — главная: hero-видео, направления, евродерево, этапы
balkony.html      — балконы: остекление, обшивка, утепление, мебель, беседки
okna.html         — окна: установка ПВХ/евродерево + полный перечень ремонта
remont.html       — ремонт: санузлы, черновые/чистовые работы, дизайн-проекты
o-kompanii.html   — о компании: принципы, история с 2018 года
kontakty.html     — контакты: телефон, ВКонтакте, бесплатный выезд

css/style.css     — дизайн-система (Golos Text + JetBrains Mono, самохостинг)
js/main.js        — шапка, мобильное меню, hero-видео, reveal-анимации
fonts/            — woff2 (кириллица + латиница), внешних запросов нет
assets/video/     — hero-видео: 1080p (~3,2 МБ) и мобильная версия (~0,9 МБ)
assets/img/       — постер видео, og-cover, favicon
```

## Перед публикацией

1. Замените домен-заглушку `https://spektr-mgn.ru/` на реальный —
   он используется в `<link rel="canonical">`, Open Graph, `robots.txt`
   и `sitemap.xml`.
2. Больше ничего настраивать не нужно: шрифты и видео лежат в репозитории,
   сторонних скриптов и счётчиков нет.
