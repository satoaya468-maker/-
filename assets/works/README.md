# Фото работ для галереи

Положите сюда 5 фотографий ваших балконов с именно такими именами:

```
work-1.jpg   — графит/дерево: панели под дерево, шкаф и скамья
work-2.jpg   — лаунж-зона: барная стойка, кресло-мешок, LED-подсветка
work-3.jpg   — скандинавия: светлая отделка, сушилки, подвесные светильники
work-4.jpg   — тёплое дерево: деревянный шкаф-купе, белая обшивка
work-5.jpg   — шкаф и скамья: бежевый шкаф-купе, зона хранения
```

Подойдут `.jpg`, `.png` или `.webp` — если меняете расширение, поправьте
ссылки в `index.html` (атрибуты `src` и `data-full` у блоков `.work`).

Лучше всего смотрятся **вертикальные** фото (примерно 3:4). Пока файлов нет,
в галерее автоматически показываются похожие по стилю изображения-заглушки —
сайт не выглядит «пустым».

Подписи к работам заданы в `index.html` (блоки `.work__cap`) — при желании
поменяйте под свои проекты.
