# Paw Studio

Сайт салона груминга для собак и кошек. Одностраничный лендинг с разделом
журнала: услуги, цены, сравнение «до и после», команда, онлайн-запись,
отзывы, вопросы, статьи и контакты. Весь контент на русском.

## Стек

- **Vite 6** + **React 19** + **TypeScript** (strict)
- **Tailwind CSS v4** — токены темы описаны через `@theme` в `src/styles/global.css`
- **Motion** — появление секций, мобильное меню, состояние формы
- **Lenis** — инерционный скролл и переходы по якорям
- **React Router** — маршруты журнала и политики, обе страницы ленивые
- **Phosphor Icons** — единый набор иконок, стиль `light`

## Запуск

```bash
npm install
npm run dev          # разработка, http://localhost:5173
npm run build        # сборка в dist/
npm run preview      # предпросмотр сборки
npm run typecheck    # проверка типов
```

## Структура

```
src/
  components/
    layout/     шапка, мобильное меню, подвал
    home/       секции главной страницы
    ui/         переиспользуемые примитивы (аккордеон, слайдер «до/после», …)
  data/         весь контент: услуги, цены, команда, отзывы, вопросы, статьи
  lib/          скролл, появления, форматирование, утилиты
  pages/        главная, статья журнала, политика
  styles/       токены и глобальные стили
```

Контент отделён от вёрстки: тексты, цены, статьи и подписи правятся
в `src/data/*` без изменения компонентов.

## Фотографии

`src/data/photos.slots.json` — реестр фотослотов (ключ, кадр, размеры, alt).
Порядок источников для каждого слота:

1. локальный файл `src/assets/photos/<key>.jpg`, если он есть;
2. удалённый кадр Unsplash;
3. фирменный фолбэк в `<SmartImage>`: тёплая поверхность, знак лапы и подпись.

Из-за третьего пункта на сайте не бывает «битых» картинок: если кадр не
загрузился, слот выглядит как осознанный элемент дизайна, а не как ошибка.

```bash
npm run photos       # скачать кадры и пережать через sharp в src/assets/photos
```

Перед продакшеном стоковые кадры заменяются съёмкой салона: достаточно
положить файлы с теми же именами в `src/assets/photos/` — сборка подхватит
их автоматически, приоритет у локальных файлов.

Для оценки вёрстки без доступа к CDN есть заглушки нужных пропорций:

```bash
node scripts/qa-placeholders.mjs         # создать
node scripts/qa-placeholders.mjs clean   # удалить
```

## Визуальная проверка

```bash
npm run preview &
npm run shots        # скриншоты всех секций на 390px и 1440px в shots/
```

Скрипт заодно проверяет горизонтальное переполнение и ошибки консоли.

## Что нужно доделать при внедрении

- Форма записи собирает и валидирует данные, но отправка сейчас заглушка
  (`Booking.tsx`, комментарий у `setStatus('sending')`). Подключите endpoint
  CRM или мессенджер-бота.
- Реквизиты, адрес, телефон и ссылки на соцсети лежат в `src/data/site.ts`.
- Домен в `index.html` (`canonical`, Open Graph, JSON-LD) и картинка `og.jpg`.

## Доступность

Семантические лендмарки и заголовки, видимый фокус, полная работа с
клавиатуры (меню, аккордеон, слайдер «до/после» на стрелках), контраст
текста не ниже 4.5:1, `prefers-reduced-motion` отключает движение,
оставляя мгновенное появление.
