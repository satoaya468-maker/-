# Design

Визуальная система Paw Studio. Регистр — brand: сайт и есть продукт.

## Theme

Светлая, единственная. Сцена: владелица шпица листает сайт днём на телефоне в
светлой квартире; салон — светлое спокойное пространство с деревом и льном.
Тёмной темы нет намеренно (анти-паттерн «dark потому что красиво» из брифа).
Одна тёмная хвойная полоса (запись) — цветовой блок, не смена темы.

## Color

Стратегия: Restrained + один Committed-блок. Нейтрали несут 90% поверхности,
шалфей — единственный интерактивный акцент, бежевый — тёплая подложка секций.

## Typography

Контраст осей: книжная антиква + русский гротеск.

- **Literata Variable** (opsz auto) — дисплей и заголовки. Голос «спокойной
  книги об уходе за животными»: литературно, тепло, без свадебного глянца.
  Вес 500–560, трекинг −0.015…−0.022em, `text-wrap: balance`.
- **Golos Text Variable** — текст, UI, формы, цены. Русская гарнитура
  Paratype: естественный ритм кириллицы, «уличная» ясность.

Шкала (fluid, ratio ≈ 1.3): display 38→62, h2 30→44, h3 19–21 (Golos 600),
body 17/1.65, small 15, caption 13.5. Строка текста ≤ 68ch.

Русская микротипографика обязательна: «ёлочки», тире по правилам языка,
узкий неразрывный пробел в числах и перед ₽ («3 500 ₽»), буква «ё».

## Shape & Elevation

Радиусы по ролям, единая система: контролы — pill (999); поля — 12;
карточки — 20; крупные медиа — 24. Тени тёплые (от `#171714`), двухслойные,
едва заметные; рельеф в основном строится хэйрлайнами и сменой bg↔surface.

## Layout

Контейнер 1240px, боковые поля clamp(20→40px). Вертикальный ритм секций
clamp(72→136px), варьируется: плотнее вокруг связанных блоков (цены → запись).
Композиции асимметричные (5/7, 4/8), без повторения одной сеточной семьи
в соседних секциях. Без «бровок»-капсов над каждым заголовком.

## Imagery

Фотография light-and-air: естественный свет, фактура шерсти, никакого глянца.
Технически: семантический реестр слотов (`src/data/photos.ts`) → удалённый
URL + локальный оверрайд. Каждый слот имеет художественный фолбэк (тёплая
поверхность + знак лапы + подпись), сломанных картинок не существует.
`npm run photos` скачивает и пережимает все слоты через sharp для
самостоятельного хостинга в продакшене; финальная замена — съёмка клиента.

## Motion

Тихий, дорогой. Материал: opacity + translateY(12–16px), длительность 0.55–0.7s,
easing `cubic-bezier(0.23, 1, 0.32, 1)`, stagger 60–80ms только внутри одного
списка. UI-переходы ≤ 220ms, кнопки `scale(0.97)` на нажатие. Lenis для
инерции скролла (lerp 0.11). `prefers-reduced-motion`: движение выключено,
остаётся мгновенное появление. Ничего не крутится, не плавает и не мигает.

## Voice

Спокойный русский без восклицаний и канцелярита. Цифры честные и «неровные»
(6 400 питомцев, 214 отзывов). Кнопка всегда называет действие: «Записаться»,
«Смотреть цены». Одна интенция — одна формулировка на всю страницу.
