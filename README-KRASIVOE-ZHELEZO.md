# Красивое железо — сайт

Лазерная резка металла 0,5–20 мм, порошковая окраска и сварка. Магнитогорск,
ул. Советской Армии, 2.

Чистый HTML + CSS + vanilla JS. Ни сборки, ни фреймворков: файлы заливаются
на shared-хостинг по FTP и работают как есть.

Главное действие сайта — **отправить чертёж в Telegram**. Форма загрузки файла
осталась, но стоит ниже и тише: она для тех, кто зашёл с компьютера.

```

assets/js/main.js          форма, галерея, виджет вопросов, анимации
images/                    изображения (сейчас — заглушки, см. раздел 6)

.htaccess / .user.ini      лимиты загрузки 20 МБ, кэш, безопасность

scripts/parts/             содержимое страниц для сборщика
scripts/make-placeholders.php  генератор картинок-заглушек
```

### Как править шапку, подвал или форму

Шапка, меню, подвал, мобильная панель, виджет вопросов, блок Telegram и форма
расчёта общие для всех страниц. Правятся в двух местах:

* `scripts/build-pages.py` — каркас, блок Telegram, виджет;
* `scripts/parts/_form.html` — форма расчёта.

После правки пересобрать:

```bash
python3 scripts/build-pages.py
```

Текст конкретной страницы — в `scripts/parts/<имя>.part.html`.
Можно править и готовые `.html` напрямую, но тогда не запускайте сборщик:
он их перезапишет.

## 3. Виджет вопросов

Кнопка «Спросить по вашей детали» в правом нижнем углу. Открывается только
по клику, сама не выпрыгивает и не мигает.

Внутри: приветствие, четыре готовых вопроса, пятый пункт «Другой вопрос»
с полем свободного ввода. Любая ветка заканчивается формой «имя / телефон /
что за деталь», заявка уходит тем же `send.php` в Telegram и помечается там
как «ВОПРОС ИЗ ВИДЖЕТА НА САЙТЕ».

**Ответы правятся в одном месте** — объект `QA` в начале раздела 10
`assets/js/main.js`:

```js
var QA = [
  { id: 'inox', q: 'Режете нержавейку?', a: 'Да. Кроме нержавейки — …' },
  …
];
var CHAT_GREETING = 'Здравствуйте. Отвечаем по резке, окраске и сварке. …';
```

Держите ответы согласованными с данными страниц: толщины 0,5–20 мм,
форматы DXF/DWG/PDF/JPG, расчёт от 1 часа. Добавить пятый вопрос — просто
дописать объект в массив, разметку менять не нужно.

Никаких внешних сервисов и библиотек: это обычный JS, работающий локально.

## 4. Настройка Telegram (10 минут)

1. **Создать бота.** В Telegram найдите `@BotFather` → `/newbot` → имя и username
   (например `KrasivoeZhelezoBot`). BotFather пришлёт токен вида
   `7123456789:AAF-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

2. **Узнать chat_id.**
   - Заявки лично мастеру: напишите боту `/start`, затем откройте
     `@userinfobot` — он покажет ваш ID (число вида `123456789`).
   - Заявки в общую группу: создайте группу, добавьте туда бота
     **и дайте ему право писать**, затем откройте в браузере
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите
     `"chat":{"id":-1001234567890}`. ID группы — с минусом, копировать целиком.

3. **Вписать в `config.php`:**

   ```php
   'tg_token'    => '7123456789:AAF-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx',
   'tg_chat_id'  => '123456789',
   'tg_username' => 'KrasivoeZhelezoBot',   // без «@»
   ```

4. **Продублировать username** в `scripts/build-pages.py` (`TG_USER`) и
   `assets/js/main.js` (`CFG.tgUser`), затем пересобрать страницы.

5. **Проверить.** Отправьте тестовую заявку с файлом: в чат должны прийти
   два сообщения — текст заявки и сам чертёж документом. Отдельно проверьте
   кнопку «Отправить чертёж в Telegram»: она должна открывать чат
   с подставленным текстом «Здравствуйте! Нужен расчёт: ».

**Если не пришло:**
- Бот не может писать первым — сначала напишите ему `/start`.
- Для группы: бот должен быть участником, а не просто «добавлен».
- Смотрите `logs/send.log` — туда пишется ответ Telegram с причиной.
- Хостинг без cURL — форма честно сообщит об этом в ответе.

**Безопасность:** `config.php` содержит токен. Он закрыт от чтения через
`.htaccess`, но не публикуйте его в открытых репозиториях. Если токен утёк —
`/revoke` у BotFather.

## 5. Заливка на reg.ru

### Через файловый менеджер (проще)

1. Панель управления reg.ru → **Хостинг** → **Файловый менеджер**.
2. Зайдите в папку сайта: `/www/ваш-домен.ru/` (у некоторых тарифов —
   `public_html`).
3. Удалите тестовый `index.html`, если он там есть.
4. Загрузите **содержимое** этой папки (не саму папку!): все `.html`,
   `favicon.svg`, `robots.txt`, `sitemap.xml`, `.htaccess`, `.user.ini`,
   `send.php`, `config.php`, папки `assets/` и `images/`.

### Через FTP (быстрее)

1. В панели reg.ru → **Хостинг** → **FTP-доступ**: хост, логин, пароль.
2. FileZilla → Файл → Менеджер сайтов → Новый сайт:
   - Хост: `ftp.ваш-домен.ru`, порт 21, протокол FTP, шифрование «явное TLS»
   - Пользователь и пароль из панели
3. Включите Сервер → «Принудительно отображать скрытые файлы», иначе
   `.htaccess` и `.user.ini` не зальются и лимит 20 МБ не заработает.
4. Справа откройте `/www/ваш-домен.ru/`, слева — папку с сайтом,
   выделите содержимое и перетащите.

### После заливки

1. **PHP.** Панель → «Управление PHP»: версия **8.0 и выше**,
   расширения `curl` и `fileinfo` включены (обычно по умолчанию).
2. **Права.** Папке `logs/` — права `755`, чтобы PHP мог писать лог.
3. **SSL.** Панель → SSL-сертификаты → выпустить бесплатный Let's Encrypt.
   После выпуска раскомментируйте блок редиректа на HTTPS в конце `.htaccess`.
4. **Проверка.** С телефона: отправьте заявку через форму и через виджет,
   нажмите кнопку Telegram и кнопки нижней панели.
5. **Лимит 20 МБ.** Если большой файл не грузится — значит `.htaccess`
   с `php_value` не сработал: удалите этот блок, `.user.ini` сделает то же самое.
6. **Индексация.** Яндекс.Вебмастер и Google Search Console → добавить сайт,
   отправить `sitemap.xml`.

### Галерея работ

Фотографий работ в `images/` больше нет — вместо них на страницах стоят
**размеченные места**: рамка, иконка камеры и подпись, что там будет
(«Ворота кованые», «Лестница с косоуром», «Мангал», «Вывеска», «Навес»,
«Резка по чертежу»). На главной шесть мест, на странице «Работы» — двенадцать
с фильтром по типу.

Как появятся снимки, каждый блок `<div class="slot">` заменяется на:

```html
<button class="work" data-cat="vorota" data-cat-label="Ворота" data-title="Откатные ворота">
  <picture>
    <source srcset="images/works/vorota-01.webp" type="image/webp">
    <img src="images/works/vorota-01.jpg" alt="Откатные ворота с лазерным узором"
         width="1200" height="900" loading="lazy" decoding="async">
  </picture>
  <span class="work__cap">
    <span class="work__tag">Ворота</span>
    <span class="work__title">Откатные ворота</span>
  </span>
</button>
```

Фильтры и просмотр по клику подхватят их сами — JS менять не нужно.
Инструкция продублирована комментарием в `scripts/parts/raboty.part.html`.

Пересобрать заглушки для остальных изображений:

```bash
php scripts/make-placeholders.php
```

## 7. Что нужно запросить у заказчика

1. **Username в Telegram** — куда ведут все главные кнопки. Сейчас `USERNAME`.
2. **Реальный номер телефона** — сейчас везде плейсхолдер `+7 909 749-XX-XX`.
3. **Домен** — на какой адрес заливаем.
4. **Часы работы полностью** — известно только «с 9:00». Нужно время закрытия
   и выходные, иначе блок расписания и микроразметка неполные.
5. **Три отзыва из 2ГИС** — текст, имя, месяц. Ничего не выдумано, стоят пустые
   заготовки. Рейтинг 4,9 / 24 оценки / 17 отзывов — уже реальные.
6. **Ссылка на группу ВКонтакте.**
7. **Ссылка на карточку 2ГИС** — для кнопки «смотреть в 2ГИС».
8. **Предельные толщины по материалам** — 0,5–20 мм по стали известно, нужны
   пределы по нержавейке, оцинковке и алюминию.
9. **Фактический допуск станка** (например «±0,1 мм на детали до 500 мм»).
10. **Габарит камеры и печи** порошковой окраски.
11. **Какие цвета RAL всегда в наличии**, а какие под заказ.
12. **Реквизиты** — ИП или ООО, название, ИНН, ОГРН, расчётный счёт, НДС.
13. **Фотографии** по списку из раздела 6 и снимки работ под размеченные места.
14. **Логотип в векторе**, если есть — сейчас знак собран из типографики.
15. **Юридическое лицо для политики конфиденциальности** и дата вступления
    в силу.

## 8. Палитра и типографика

```
--paper   #FAFAF8   фон страницы
--surface #F0F0EE   карточки и полосы
--line    #D8D8D4   границы, направляющие чертежа

```

Акцент используется ровно в трёх местах на экране: главная кнопка
(«Отправить чертёж в Telegram»), кнопка виджета и линия реза в hero.
Плюс hover-состояния. Больше нигде — если появилось четвёртое пятно,
что-то поехало.

Моноширинный шрифт (JetBrains Mono) — **только на числах**: толщины, мм,
часы, рейтинг, габариты, коды RAL, вес файла. Весь остальной текст —
Inter / Inter Tight, без капса и разрядки.

## 9. Проверено

- HTML: один `<h1>` на страницу, теги сбалансированы, `alt` у всех изображений,
  нет инлайновых стилей и внешних CDN для картинок.
- Ни горизонтального переполнения, ни ошибок JS на семи страницах
  при 1440px и 360px.
- Форма: валидация, маска телефона, приём и удаление файлов, отсев неверных
  форматов, состояния загрузки, успеха и ошибки, таймер «ответим за час».
- Виджет: пять кнопок, свободный ввод, форма контактов, состояния отправки,
  успеха и ошибки, закрытие по Escape, на мобиле — на весь экран.
- `send.php`: honeypot, отсев мгновенной отправки, лимит 5 заявок за 10 минут
  с одного IP, проверка расширения и MIME, безопасное имя файла.
- Мобильная панель: две кнопки, показывается только уже 768px.
- `prefers-reduced-motion`: анимации, параллакс и линия реза выключаются.
