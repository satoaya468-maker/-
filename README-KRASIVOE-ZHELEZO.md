# Красивое железо — сайт

Лазерная резка металла 0,5–20 мм, порошковая окраска и сварка. Магнитогорск,
ул. Советской Армии, 2.

Чистый HTML + CSS + vanilla JS. Ни сборки, ни фреймворков: файлы заливаются
на shared-хостинг по FTP и работают как есть.

---

## 1. Структура

```
index.html                 главная: два потока, форма чертежа, толщины, работы, репутация
lazernaya-rezka.html       материалы, шкала толщин, форматы файлов, расчёт
poroshkovaya-okraska.html  процесс по шагам, палитра RAL, условия
svarka.html                способы, что собираем, порядок работ
raboty.html                галерея с фильтрами и лайтбоксом
kontakty.html              адрес, карта, каналы связи, реквизиты
politika.html              политика конфиденциальности (noindex)

assets/css/style.css       вся дизайн-система, один файл
assets/js/main.js          форма, галерея, лайтбокс, анимации
images/                    все изображения (сейчас — заглушки, см. раздел 4)
send.php                   приём заявки → Telegram
config.php                 токен бота и chat_id
.htaccess / .user.ini      лимиты загрузки 20 МБ, кэш, безопасность

scripts/build-pages.py     сборщик страниц из общего каркаса (нужен только разработчику)
scripts/parts/             содержимое страниц для сборщика
scripts/make-placeholders.php  генератор картинок-заглушек
```

### Как править шапку или подвал

Шапка, меню, подвал, мобильный док и форма расчёта общие для всех страниц.
Правьте их в `scripts/build-pages.py` (каркас) и `scripts/parts/_form.html` (форма),
затем пересоберите:

```bash
python3 scripts/build-pages.py
```

Текст конкретной страницы правится в `scripts/parts/<имя>.part.html`.
Можно править и готовые `.html` напрямую — но тогда не запускайте сборщик,
он их перезапишет.

## 3. Настройка Telegram-бота (10 минут)

1. **Создать бота.** В Telegram найдите `@BotFather` → `/newbot` → имя и username
   (например `KrasivoeZhelezoBot`). BotFather пришлёт токен вида
   `7123456789:AAF-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

2. **Узнать chat_id.**
   - Заявки лично мастеру: напишите боту `/start`, затем откройте
     `@userinfobot` — он покажет ваш ID (число вида `123456789`).
   - Заявки в общую группу: создайте группу, добавьте туда бота
     **и дайте ему право писать**, затем откройте в браузере
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите
     `"chat":{"id":-1001234567890}`. ID группы — с минусом, копировать целиком.

3. **Вписать в `config.php`:**

   ```php
   'tg_token'   => '7123456789:AAF-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx',
   'tg_chat_id' => '123456789',
   ```

4. **Проверить.** Откройте сайт, отправьте тестовую заявку с файлом.
   В чат должны прийти два сообщения: текст заявки и сам чертёж документом.

**Если не пришло:**
- Бот не может писать первым — сначала напишите ему `/start`.
- Для группы: бот должен быть участником, а не просто «добавлен».
- Смотрите `logs/send.log` — туда пишется ответ Telegram с причиной.
- Хостинг без cURL — форма честно сообщит об этом в ответе.

**Безопасность:** `config.php` содержит токен. Он закрыт от чтения через
`.htaccess`, но не публикуйте его в открытых репозиториях. Если токен утёк —
`/revoke` у BotFather.

## 4. Заливка на reg.ru

### Через файловый менеджер (проще)

1. Панель управления reg.ru → **Хостинг** → **Файловый менеджер**.
2. Зайдите в папку сайта: `/www/ваш-домен.ru/` (у некоторых тарифов —
   `public_html`).
3. Удалите тестовый `index.html`, если он там есть.
4. Загрузите **содержимое** этой папки (не саму папку!): все `.html`,
   `favicon.svg`, `robots.txt`, `sitemap.xml`, `.htaccess`, `.user.ini`,
   `send.php`, `config.php`, папки `assets/` и `images/`.
   Папки `scripts/`, `logs/`, `.claude/` и файлы `spektr*` заливать не нужно.

### Через FTP (быстрее для 40 файлов)

1. В панели reg.ru → **Хостинг** → **FTP-доступ**: хост, логин, пароль.
2. FileZilla → Файл → Менеджер сайтов → Новый сайт:
   - Хост: `ftp.ваш-домен.ru`, порт 21, протокол FTP, шифрование «явное TLS»
   - Пользователь и пароль из панели
3. Справа откройте `/www/ваш-домен.ru/`, слева — папку с сайтом.
4. Выделите содержимое слева и перетащите направо.

### После заливки

1. **PHP.** Панель → «Управление PHP»: версия **8.0 и выше**,
   расширения `curl` и `fileinfo` включены (обычно по умолчанию).
2. **Права.** Папке `logs/` — права `755`, чтобы PHP мог писать лог.
3. **SSL.** Панель → SSL-сертификаты → выпустить бесплатный Let's Encrypt.
   После выпуска раскомментируйте блок редиректа на HTTPS в конце `.htaccess`.
4. **Проверка формы.** Отправьте заявку с телефона: файл должен долететь
   в Telegram, а на экране появиться зелёная панель с таймером.
5. **Лимит 20 МБ.** Если большой файл не грузится — значит `.htaccess`
   с `php_value` не сработал: удалите этот блок, `.user.ini` сделает то же самое.
6. **Индексация.** Яндекс.Вебмастер и Google Search Console → добавить сайт,
   отправить `sitemap.xml`.

## 6. Что нужно запросить у заказчика

1. **Реальный номер телефона** — сейчас везде плейсхолдер `+7 909 749-XX-XX`,
   и WhatsApp ведёт на `79097490000`.
2. **Домен** — на какой адрес заливаем.
3. **Часы работы полностью** — известно только «с 9:00». Нужно время закрытия
   и выходные, иначе блок расписания и микроразметка неполные.
4. **Три отзыва из 2ГИС** — текст, имя, месяц. Ничего не выдумано, стоят пустые
   заготовки.
5. **Ссылка на группу ВКонтакте.**
6. **Ссылка на карточку 2ГИС** (для кнопки «Открыть в 2ГИС»).
7. **Предельные толщины по материалам** — 0,5–20 мм по стали известно, нужны
   пределы по нержавейке, оцинковке и алюминию.
8. **Фактический допуск станка** (например «±0,1 мм на детали до 500 мм») —
   технолог ищет на странице резки именно эту строку.
9. **Габарит камеры и печи** порошковой окраски — второй вопрос заказчика
   после цвета.
10. **Какие цвета RAL всегда в наличии**, а какие под заказ.
11. **Реквизиты** — ИП или ООО, название, ИНН, ОГРН, расчётный счёт, НДС.
12. **Фотографии** по списку из раздела 5.
13. **Логотип в векторе**, если есть — сейчас знак собран из типографики.
14. **Юридическое лицо для политики конфиденциальности** и дата вступления
    в силу.

## 7. Проверено

- HTML: один `<h1>` на страницу, теги сбалансированы, `alt` у всех изображений,
  нет инлайновых стилей и внешних CDN для картинок.
- Форма: валидация имени/телефона/согласия, маска телефона, приём и удаление
  файлов, отсев неверных форматов, состояния загрузки и результата.
- `send.php`: honeypot, отсев мгновенной отправки, лимит 5 заявок за 10 минут
  с одного IP, проверка расширения и MIME, безопасное имя файла.
- Галерея: фильтры, лайтбокс с клавиатурой (`←`, `→`, `Esc`), ловушка фокуса,
  свайп на телефоне.
- Контраст: `--paper` 17,7:1, `--muted` 6,1:1, `--spark` 5,96:1 к фону —
  все выше 4.5:1. Подписи на образцах RAL считались по контрасту.
- `prefers-reduced-motion`: анимации, параллакс и линия лазера выключаются.
