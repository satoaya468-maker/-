# Спектр — премиальный лендинг

Кинематографичный одностраничный сайт для ООО «Спектр» (Магнитогорск): окна,
балконы и комплексный ремонт под ключ. Чистый HTML/CSS/JS без сборки —
загрузите содержимое репозитория на любой хостинг.

## Структура

```
index.html            — страница с SEO-метатегами, Open Graph и schema.org
css/style.css         — дизайн-система (Stripe-вдохновлённый минимализм)
js/main.js            — scroll-cinematic движок + анимации
assets/frames/hero/   — кадры hero-видео для скраба по скроллу (создаёт CI)
assets/img/           — постер, og-cover, фото балкона (создаёт CI)
assets/video/         — исходное hero-видео (создаёт CI)
scripts/build-frames.sh — локальная сборка кадров (нужен ffmpeg)
```

## Медиа-пайплайн

Hero-видео и фото сгенерированы в Higgsfield AI. Workflow
`.github/workflows/fetch-assets.yml` скачивает их, нарезает видео на
120 webp-кадров и коммитит в ветку. Если GitHub Actions выключен —
включите его в настройках репозитория и запустите workflow вручную
(Actions → Build media assets → Run workflow), либо выполните локально
`./scripts/build-frames.sh`.

Пока кадры не собраны, сайт автоматически работает в запасных режимах:
скраб самого видео, затем статичный постер/градиент — страница остаётся
полностью рабочей.

## Перед публикацией

1. Замените `https://spektr-mgn.ru/` в `index.html`, `robots.txt` и
   `sitemap.xml` на реальный домен.
2. Вставьте ссылку на группу ВКонтакте (кнопка «Написать ВКонтакте»,
   помечена `TODO` в `index.html`).
