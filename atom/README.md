# Сервисный центр «Атом» — сайт

Статический многостраничный сайт. Никаких фреймворков и внешних зависимостей:
всё работает из файловой системы и с любого хостинга.

## Структура

| Файл | Страница |
|---|---|
| `index.html` | Главная |
| `uslugi.html` | Услуги и цены |
| `remont-televizorov.html` | Ремонт телевизоров (детальная услуга) |
| `o-kompanii.html` | О компании |
| `garantii.html` | Гарантии |
| `otzyvy.html` | Отзывы |
| `contakty.html` | Контакты |
| `styles.css` | Общая таблица стилей |
| `app.js` | Формы, меню, карусель, FAQ, карта |

## Сборка

Шапка, подвал и повторяемые блоки описаны один раз в `tools/build.py`.
После правок запустите:

```
python3 tools/build.py
```

Изображения плат генерируются процедурно (нет внешних CDN):

```
python3 tools/gen_textures.py     # требует pillow и numpy
```

## Что нужно заменить перед публикацией

1. **Отзывы** — тексты в `tools/build.py` (список `REVIEWS`) помечены как демо-контент.
   Заменить на реальные отзывы с Яндекс.Карт.
2. **Команда** на `o-kompanii.html` — список `team` в `build.py`, имена указаны сокращённо.
3. **Юридические реквизиты** на `contakty.html` — сейчас стоит формулировка
   «предоставляем по запросу». Подставить фактические ИНН/ОГРН, когда они будут.
4. **Обработка форм** — сейчас заглушка: `console.log` + модалка успеха.
   Точка подключения бэкенда или CRM — функция `submitLead()` в `app.js`.
5. **Фотографии** — вместо фотобанка используются процедурно отрисованные макро-снимки
   плат. Слоты можно заменить на реальные фото мастерской: `assets/img/board-*.jpg`.
